# ՀԱՅԵՐ — միասնական հայկական համայնք

HAYER-ը նախատեսված է որպես միասնական սոցիալական հարթակ՝ HAYID նույնականացմամբ, սեփական Feed-ով, համայնքներով և հաղորդակցությամբ։

## Պարտադիր բովանդակային կանոն

**HAYER-ի Feed-ը, որոնումը, Explore-ը, տեսանյութերի բաժինը և համայնքները պետք է ցուցադրեն միայն HAYER-ի օգտատերերի ստեղծած նյութերը։** Mastodon, Pixelfed, Lemmy, PeerTube կամ այլ արտաքին հարթակների օգտատերերի հրապարակումները չեն ներմուծվում և չեն ցուցադրվում որպես HAYER բովանդակություն։ Արտաքին սերվերների ցանկերը կարող են օգտագործվել միայն ենթակառուցվածքի հայտնաբերման համար։

## Ենթակառուցվածք

- Օգտատերը չի տրամադրում կամ սպասարկում սեփական VPS, սերվեր, դոմեն կամ վճարովի backend։
- HAYER-ի Cloudflare Worker-ը (`hayer-api`) և D1 տվյալների բազան (`hayer-core`) հեռացված են։
- Այլ Cloudflare նախագծերը չեն փոփոխվել։
- Cloudflare R2 չի օգտագործվում։
- Ֆայլերը պետք է պահվեն գործող հանրային ֆեդերացված ծառայություններում՝ միայն այն դեպքում, երբ դրանց API-ն և օգտագործման կանոնները թույլ են տալիս իրական upload-ը։
- Անձնական ֆայլերը պետք է գաղտնագրվեն հաճախորդի սարքում մինչև վերբեռնումը։
- Հանրային սերվերների ցանկը տվյալների կրկնօրինակում չէ։ Յուրաքանչյուր ծառայության հաշիվը, սահմանափակումները և տվյալները մնում են իր օպերատորի վերահսկողության տակ։

## Ինչու է backend-ի փոխարինումը պարտադիր

Ստատիկ GitHub Pages էջը չի կարող ինքնուրույն ապահովել գլոբալ օգտատերերի նույնականացում, ընդհանուր Feed, անձնական հաղորդագրությունների պահպանում կամ բազմասարքային համաժամացում։ Դրա համար անհրաժեշտ է միացնել իրական ֆեդերացված պրոտոկոլի հաշիվներ և սենյակներ։ Matrix-ը կարող է տրամադրել հաշիվներ, սենյակներ, հաղորդագրություններ և մեդիա, սակայն հանրային homeserver-ների գրանցման կանոնները, CORS-ը, ֆայլերի սահմանաչափերն ու պահման քաղաքականությունները տարբեր են։ Հետևաբար ֆունկցիաները պատրաստ չեն համարվում, մինչև իրական հաշիվներով ու սերվերներով չստուգվեն։

## Ստուգում

```bash
python scripts/validate.py
```

Ստատիկ կառուցման ստուգումը չի ապացուցում, որ հաշիվները, հաղորդագրությունները, upload-ը կամ զանգերը աշխատում են իրական սերվերներում։
